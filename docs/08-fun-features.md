# 08 · 彩蛋与整蛊（只列能实现的）

> 这个产品有点偏整蛊，但**大部分是正经东西**。本文档只收那些**有数据支撑、能真做出来**的点子。
> 判断标准只有一条：**数据从哪来？说不出来就不做。**

---

## 1. 已经做进设计稿的

### 1.1 罪状清单
每次白给阵亡列一条：时间 + 地点 + 可查证理由。
数据来源：`game-timelines` 的 `CHAMPION_KILL`（`victimId / timestamp / position`）+ `participantFrames` 的 `currentGold`。

> 这条其实是**正经功能**，只是文案可以写得毒。它是全产品最硬的差异化。

### 1.2 死亡位置图
把 `position{x,y}` 投影到嚎哭深渊的单线上，实心红 = 白给，空心 = 正常。
一眼看出"这人死得有多冒进"。

### 1.3 KDA 美颜开关
顶栏一个开关，一开：
```
2 / 11 / 4   →   参团 6 · 钢铁意志 ×11
罪 状        →   功 劳 簿
在 犯 罪     →   灵 魂 人 物
阵亡 11      →   钢铁意志 ×11
```
纯文案替换，零风险，截图发群里效果很好。

## 2. 建议做（数据都在）

### 2.1 成就徽章（整蛊为主，但每条都可查证）

| 成就 | 触发条件 | 来源字段 |
|---|---|---|
| **钢铁意志** | 阵亡 ≥ 12 | `stats.deaths` |
| **永不购物** | 死时携带金币 ≥ 2000 出现 ≥ 2 次 | `participantFrames.currentGold` + 死亡时刻 |
| **隐身大师** | 参团 < 35% 且阵亡 0 | `assists/kills` + `deaths` |
| **玻璃大炮** | 伤害全队第一 且 阵亡全队第一 | `totalDamageDealtToChampions` + `deaths` |
| **一面墙** | 承伤占比 ≥ 30% | `totalDamageTaken` |
| **时空行者** | 最长存活 ≥ 180 秒 | `longestTimeSpentLiving` |
| **首杀提款机** | 前 3 分钟阵亡 ≥ 2 次 | timeline 事件 |
| **团灭发动机** | 团战前 8 秒阵亡 ≥ 3 次 | FeedDeaths 算法 |
| **KDA 之神** | K/D ≥ 5 且参团 < 50% | `kills/deaths/assists` |
| **氪金战士** | 装备价值最高 且 伤害最低 | `items` 售价 + `totalDamageDealtToChampions` |
| **永不放弃** | 连败 5 局后单杀对面 MVP | 本地历史 + 本局 |
| **空血不死** | 本局唯一一次"活到团灭结束" | timeline 存活序列 |

> 实现要点：每局最多解锁 2 枚，多了就不稀奇了。徽章用 1px 线框几何图形，不用卡通插画（会破坏整套视觉）。

### 2.2 甩锅 / 吹嘘文案一键复制

按钮就在报告页顶部。模板 + 可选 AI 润色：

**甩锅版**
> "这局我 6/1/8，伤害占全队 34%。上单 11 次阵亡里有 4 次是在团战开打前 8 秒送的。数据都在这，不接受反驳。"

**吹嘘版**
> "刚才那把，我一个中单伤害占全队 34%，对面中单 14/3 也压不住我这局的输出密度。收工。"

**免责声明版（真有用）**
> "本局数据来源：Riot 官方本地接口。以上结论均可追溯到具体时间戳，不信你自己查。"

数据来源：报告页已有的结论 + 罪状清单。**纯模板拼接就能做**，AI 只是可选润色。

### 2.3 经济曲线
`participantFrames` 每分钟给 `totalGold / xp / level`，10 条线画出来，能看出"谁一直没钱"、"谁前 10 分钟就崩了"。
这是**正经功能**，不是整蛊。

### 2.4 对比上一局
同一个玩家，本局 vs 上一局，六项指标并排。数据都在 `match-history` 里，纯查表。
可以整蛊：加一句"比上局少了 3 次阵亡，有进步"。

### 2.5 开场预言（最整蛊的一个，但真的能做）
选人阶段拿队友近 20 局战绩，开局给一句预言：
> "队友 Yasuo 近 20 局胜率 41%，场均阵亡 8.2。预言：这局他会死 8 次以上。"

打完自动对答案，报「预言命中」或「预言翻车」。
数据来源：`/lol-match-history/v1/products/lol/{puuid}/matches`，国服实测可用。
> 注意措辞：**只对数据做陈述，不做人身攻击**。预言错了反而更好笑。

### 2.6 罪犯排行榜（跨局）
本地数据库里统计历史所有局：谁当「蛆王」次数最多、平均 FeedDeaths、最长连败。
这是本地功能，不需要云端。

### 2.7 分享长图
把报告渲染成竖版长图（900×1200），可以直接发群。
实现：HTML → canvas → PNG。**注意这要为竖版另排一套版式**，工作量不小，建议放最后。

## 3. 可以做但要克制

| 想法 | 风险 | 建议 |
|---|---|---|
| 队友绰号系统 | 容易变成人身攻击 | 只给正向/中性绰号，或做成用户自填 |
| 「这局不怪你」安慰模式 | 跟产品调性冲突 | 作为一个隐藏开关可以 |
| 开局弹窗嘲讽 | 打扰游戏 | **不要做**。对局中只显示状态，不评价 |
| 实时"你正在送"提醒 | 会让用户更焦虑 | **不要做** |

> 原则：**整蛊只出现在事后报告里，不出现在打游戏的时候。** 打的时候要的是信息，不是评语。

---

## 4. 明确不做

| 不做 | 原因 |
|---|---|
| OCR 截图识别符文 | 数据已经拿到了，没理由走作弊工具的路子 |
| 读内存 / 注入客户端 | 反作弊红线 |
| 预测胜负准确率 | 做不到，且会毁掉可信度 |
| 抓 op.gg / 掌盟 | 违反站点条款 |
| 任何自动化操作 | Riot 政策红线 |
| 称呼用户"傻逼/菜鸡"类 | 整蛊 ≠ 人身攻击。嘲讽对象是**行为**（"8 秒前阵亡"），不是**人** |

---

## 5. 优先级建议

| 优先 | 内容 | 理由 |
|---|---|---|
| P2 必做 | 罪状清单、死亡位置图、成就徽章 | 核心差异化，数据都在 |
| P2 可选 | 甩锅文案、经济曲线、对比上一局 | 提升粘性 |
| P3 | 开场预言、罪犯排行榜、分享长图 | 有趣但非核心 |
| 再议 | 美颜开关已做，看反馈决定要不要推广到更多文案 |

**整蛊度控制**：正经 : 整蛊 ≈ 7 : 3。正经的部分（评分、罪状、经济曲线）撑起产品价值，整蛊的部分（美颜、成就、预言）负责让人想转发。
