# 09 · 竞品对比与小功能清单

> 对比对象：LeagueAkari、OP.GG、U.GG、Porofessor、Blitz、掌上英雄联盟。
> 判断标准只有一条：**数据从哪来？说不出来就不做。**

---

## 1. 竞品在做什么

### LeagueAkari（开源，最接近我们）
源码实测的功能面：

| 模块 | 内容 |
|---|---|
| `ongoing-game` | 队友情报面板：段位 / 熟练度 / 近 N 局 / 开黑关系 / 预组队 |
| `player-tabs` | 玩家档案：战绩筛选（含「有某个符文」的组合查询）、英雄掌握度 |
| `match-history` | 战绩列表 + 单局详情（出装/符文/队伍/地图） |
| `automation` | **自动接受对局、自动 ban/pick、自动选英雄** |
| `toolkit` | 一键领取奖励、战利品/海克斯宝箱、好友工具、局内发送预设 |
| `cd-timer` | **召唤师技能冷却计时**（独立悬浮窗） |
| `opgg-window` | 接 OP.GG 数据源：出装推荐、tier list、符文推荐 |
| 其他 | 多主题、热键、直播模式（隐藏玩家名）、玩家存档 |

### 其他工具

| 工具 | 强项 | 弱项 |
|---|---|---|
| **OP.GG / U.GG** | 出装与符文推荐、tier list、对阵数据 | 只看数据不做评价，需要开网页 |
| **Porofessor / Blitz** | 实时对局分析、跑图建议、技能 CD 计时 | 多游戏分散，国内访问慢，无国服适配 |
| **掌上英雄联盟** | 官方、皮肤/活动/社区/好友 | 只有汇总数据，没有分析与评价 |

## 2. 差异化：我们有、他们没有

| 我们的功能 | 为什么别人没有 | 数据来源 |
|---|---|---|
| **白给阵亡判定** | 需要时间线逐秒归因，市面工具只统计阵亡次数 | `game-timelines` 的 `CHAMPION_KILL` |
| **罪状清单** | 同上，且要把"为什么这算白给"说清楚 | 时间线 + `participantFrames` |
| **死亡位置图** | 大乱斗单线，位置信息能直接说明"死得冒进" | `position{x,y}` |
| **人设标签**（含「肉盾」） | 峡谷工具没有"承伤算贡献"的模型 | 自建评分模型 |
| **开场预言 + 对答案** | 没人做"预言错了更好笑"这种互动 | 近 20 局战绩 |
| **符文构筑评价**（可做） | 海克斯大乱斗是新模式，工具还没跟上 | `playerAugment1..4` + gtimg 图鉴 |
| **KDA 美颜** | 纯整蛊，竞品都太正经 | 纯文案 |

**这是护城河**：别人抄得到界面，抄不到"为什么这算白给"的判定逻辑。

### B. 大乱斗专属（竞品都没做，我们该做）

> **数据支撑已实测验证**（见 07 §3.4）。三个接口都通，返回真实胜率而非推荐榜。

| # | 功能 | 数据来源 | 支撑强度 |
|---|---|---|---|
| **B1** | **符文构筑评分** | 海克斯榜 226 条 + 英雄榜 `[5]`/`[10]` | ✅ **强**。公式已按真实分布拟合，见 07 §6.4 |
| **B2** | **该拿什么符文** | 同上，按英雄 ID 反查 `bestChampionIds` + 胜率排名 | ✅ **强** |
| **B4** | **团队组合评分** | 最佳搭档榜（双人真实胜率）+ 英雄榜 `[6]-[9]`（平均死亡/参团/伤害占比/承伤占比） | ⚠️ **强，但口径要改**：见下 |
| **B5** | **对面阵容弱点** | 进游戏后英雄 ID + 最佳搭档榜反查 | ✅ 强 |
| **B6** | **经济曲线** | 时间线 `participantFrames.totalGold` 每分钟 | ✅ 强 |
| **B3** | **重随建议** | 你的历史数据 + 英雄榜胜率 | ✅ 强 |
| **B7** | **果子计时** | 大乱斗屠夫之桥果子 CD | ⚠️ 接口可能拿不到，先验 |
| **B8** | **连胜连败熔断** | 本地历史 | ✅ |
| **B9** | **今日统计** | 本地历史 | ✅ |
| **B10** | **跨局罪犯排行榜** | 本地历史 | ✅ |

#### B4 的口径修正（重要）

原计划"算坦度/输出/控制/治疗配比"——**控制和治疗没有现成字段**。gtimg 英雄表的 `keywords` 只是搜索别名（拼音缩写），不是技能标签。

改成：

| 维度 | 数据源 | 说明 |
|---|---|---|
| **组合质量（主指标）** | 最佳搭档榜 `winRate` | **实证数据**，比自己造评分可靠 |
| 坦度 / 输出配比 | gtimg `roles` + `attack/defense/magic`（1–10） | 加里奥 1/10/6、奥拉夫 9/5/3、黑暗之女 2/3/10 |
| 控制 / 治疗 | ❌ 选人阶段拿不到 | **只在赛后**用我们自己的 `timeCCingOthers` / `totalHeal` 解释，不在赛前瞎猜 |

一句话：**赛前用官方胜率说话，赛后用自己的数据解释。**

## 4. 明确不抄的（合规红线）

| 竞品功能 | 为什么不做 |
|---|---|
| **召唤师技能 CD 计时** | LeagueAkari `cd-timer`、Porofessor 都有。但这是**接口未暴露的隐藏信息**，踩 Riot 政策线。我们只显示 API 给的东西 |
| **自动接受对局** | LeagueAkari `automation` 有。自动化输入是 Riot 明令禁止的 |
| **自动 ban / pick / 选英雄** | 同上 |
| **局内打字助手** | 自动化输入 + 干扰比赛 |
| **读内存 / 注入** | 反作弊红线 |
| **抓 op.gg / 掌盟** | 违反站点条款。要数据走 LCU 或 gtimg 官方 CDN |
| **OCR 截图识别** | 数据已经拿到了，没理由走作弊工具的路子 |

> 一句话：**别人在灰色地带的部分，我们不做。** 产品价值来自「说清楚为什么」，不是「替你操作」。

## 5. 建议的实现顺序

| 阶段 | 内容 | 理由 |
|---|---|---|
| **P2** | B1 符文构筑评分 + B4 团队组合评分 + B6 经济曲线 | 大乱斗专属，竞品空白，数据都在 |
| **P2** | A1 一键领奖 + A2 战利品 + A7 直播模式 | 成本低，日常有用 |
| **P3** | B2 符文推荐 + B3 重随建议 + B5 阵容弱点 | 需要接 qq101 数据源，有适配量 |
| **P3** | A3 好友 + A5 多账号 + A6 热键 | 锦上添花 |
| **P4** | C1 成就 + C2 甩锅文案 + C4 分享长图 | 整蛊与传播 |
| **再议** | B7 果子计时 | 先验数据能不能拿到 |

---

## 6. 一句话总结

**别人做的是"数据展示"和"替你操作"，我们要做的是"替你吐槽，但每句都站得住脚"。**

具体到小功能：**符文构筑评分**（B1）是海克斯大乱斗独有的空白，别人还没跟上这个模式；**团队组合评分**（B4）和**经济曲线**（B6）是正经分析能力；其余低成本项里**一键领奖**（A1）和**直播模式**（A7）最实用。
